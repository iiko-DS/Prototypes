# Рецепты

Типовые задачи «как сделать». Если задача повторяется у нескольких людей — она должна оказаться здесь, а не в переписке.

## Уже написано

| [Поправить значение компонента](01-поправить-значение-компонента.md) | компонент выглядит не так: отступ, размер, цвет, текст |
| [Обновить базу и посмотреть страницы](02-обновить-базу.md) | начал работать, вернулся после паузы, что-то не сходится |

## Ещё стоит написать (при случае, по мере надобности)

- Как собрать новый прототип экрана из компонентов ДС.
- Как добавить новый компонент в ДС (данные страницы, платформенные значения, CSS слоя).
- Как работать с токенами: где искать нужный, когда заводить новый.
- Как подключить Figma-макет к работе над компонентом.

Пока рецепта нет — задача всё равно решается: спроси того, кто делал похожее, и потом допиши сюда то, что понял. В этом и смысл базы знаний: каждый раз, когда объясняешь в чате одно и то же, здесь должно появиться на одну страницу больше.
