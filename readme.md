# iiko DS — прототипы

Прототипы интерфейсов по дизайн-системе iiko (`iiko-ds-spec.md`). Лежат отдельно от самой ДС.

## Правила (обязательные)

- **Только компоненты ДС.** Любой блок собирается из готовых классов `ds-*` (`iiko-ds-web/components/*_DS/`, подключён `components/index.css`) и токенов (`tokens.css`). Перед сборкой — читать `iiko-ds-web/iiko-ds-spec.md` (описания, варианты, состояния, CSS компонента).
- **Макет задаёт структуру и тексты, ДС — внешний вид.** Стили макета (капс, цвета, трекинги, радиусы, внутренние паддинги/размеры) на компоненты НЕ переносим.
- Кастомные классы запрещены; допустима только обвязка раскладки и правки поверх ДС при реальном пробеле ДС (с комментарием `/* косяк ДС: … */`). Настройка компонентов — через их переменные `--ds-…`.
- Найденные пробелы ДС — в журнал `DS/fixes.md` (лежит в папке дизайн-системы; пункт следующим номером, метка «пробел ДС №N» в коде) и в подсказки на странице.
- **Папка дизайн-системы лежит рядом** (сейчас — `DS`): все подключения идут по пути `../DS/…` (стили — `../DS/components-web/…`, мобильный слой — `../DS/components-mobile/…`).
- **Сквозные организмы — из дизайн-системы**: подключаются одной строкой `../DS/connect.js` (или вручную из `../DS/organisms/…`); шапка и боковое меню не пересобираются на страницах; правила — в readme организма (`../DS/organisms/app-sidenav/readme.md`).
- Подробнее: `.github/copilot-instructions.md` в корне воркспейса.

## Как начать новую страницу

1. Создай HTML-файл **где угодно** — черновики и рабочие версии можно держать в любой своей
   папке (и сколько угодно); в этот репозиторий попадают финальные и общие страницы.
   Главное — чтобы из файла был виден путь к папке `DS`.
2. Вставь в `<head>` **одну строку** — подтянутся стили ДС, иконки, шапка и боковое меню:

```html
<script src="../DS/connect.js" defer></script>
```

3. Пиши контент из компонентов ДС (классы `ds-*`) — обёртка `.panel > .frame` создастся сама.
   Флаги: `data-no-header`, `data-no-sidenav`, `data-mobile`, `data-molecules="имя"` — см. `DS/connect.js`.

Живой пример такой страницы — **`_demo-connect.html`** в этом репозитории (одна строка подключения
и пара компонентов ДС).

Всё, что добавлено «не по ДС» (свои цвета, размеры, состояния) — помечай комментарием в коде
и перечисляй в подсказках страницы / журнале `DS/fixes.md`: дизайнеры поправят в Фигме — уберём локальное.

## Веб-КЦ (Call Center)
- [Безналичная оплата на контрагента](callcenter-noncash-payment.html) — **открывать для показа**: доработка целиком на одном экране Веб-КЦ, состояния переключаются в шапке ревью (`?state=<id>`, стрелки ← →, `?ui=0` — чистый кадр). Одиннадцать состояний: карточка заказа с платежом «Безналичный расчёт» и контрагентом · форма оплаты без колонки (безналичных типов оплаты нет) · форма оплаты с колонкой «Безналичный расчёт» последней · выбран безналичный тип без контрагента (кнопка применения недоступна + подсказка «Выберите контрагента») · окно «Контрагент»: список (наименование + тип) · поиск по наименованию · контрагент выбран · загрузка · пусто («Нет доступных контрагентов…») · оплата применена · «Отмена» сбрасывает тип оплаты. Пробелы ДС, найденные при сборке, — кнопкой «Подсказки ДС» и пунктами 34–40 в `DS/fixes.md`

## Обвязка ревью

Сквозные организмы приложения (шапка, боковое меню) живут в дизайн-системе — в соседней папке `DS`:
`../DS/organisms/app-header` и `../DS/organisms/app-sidenav` (у меню — демо стенд и полные
правила подключения: `../DS/organisms/app-sidenav/readme.md`). На страницах они подключаются
одной строкой — `../DS/connect.js` (или вручную, двумя строками из `../DS/organisms/…`).

- `device-chrome/` — подложки-корпуса устройств (телефон / планшет / десктоп) для показа кадров
- `ds-frame-nav.js` — при переходах между страницами сохраняет ширину кадра (мобильный пресет не сбрасывается на десктоп)
- `ds-sizes-toggle.js` — переключатель «Компоненты: Mobile / Desktop» на одном и том же кадре
- `touch-mode.js` + `touch-mode.css`, `touch-hover-off.css` — тач-режим: тап по строке раскрывает действия, протяжка мышью = горизонтальный скролл, ховеры отключены
