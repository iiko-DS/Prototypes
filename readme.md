# iiko DS — прототипы

Прототипы интерфейсов на компонентах дизайн-системы iiko и база знаний по работе с ней.

## Как собрать прототип

Одна короткая инструкция — [`prototyping-guide/как-работать-с-ДС.md`](prototyping-guide/как-работать-с-ДС.md):
страница подключает ДС одной строкой (ничего скачивать не нужно) и собирается из компонентов
`ds-*`; инструкцию можно просто отдать ИИ-агенту — «собери прототип, используя нашу ДС».

Живой пример такой страницы — **`demo-connect.html`** в этом репозитории (одна строка подключения
и пара компонентов ДС).

## Что лежит в репозитории

- `demo-connect.html` — живой пример страницы: одна строка подключения; хедер и сайднав приходят сами, контент — динамический контейнер под любые приложения iiko;
- `device-chrome/` — подложки-корпуса устройств (телефон / планшет / десктоп) для показа кадров;
- `ds-frame-nav.js` — при переходах между страницами сохраняет ширину кадра (мобильный пресет не сбрасывается на десктоп);
- `ds-sizes-toggle.js` — переключатель «Компоненты: Mobile / Desktop» на одном и том же кадре;
- `touch-mode.js` + `touch-mode.css`, `touch-hover-off.css` — тач-режим: тап по строке раскрывает действия, протяжка мышью = горизонтальный скролл, ховеры отключены;
- `review-notes.md` — указатель на журнал косяков ДС (`DS/fixes.md`);
- `git-workflow.md` — как работаем с гитом (ветки и Pull Request);
- `prototyping-guide/` — база знаний: правила, рецепты, скиллы для ИИ-агентов, журнал решений, инструкция «как работать».
