# Обновить базу

Когда нужно: вернулся после паузы или хочешь, чтобы база была свежей.

## Порядок

```
python pull.py      # забрать свежий main из репозиториев DS и Prototypes
```

## Что делает `pull.py`

- **`pull.py`** — забирает свежий `main` из репозиториев `DS` и `Prototypes`. Если в каком-то лежат незакоммиченные правки или ты сидишь в своей ветке, он об этом скажет и ничего не тронет — работа не потеряется.

## Если pull ругается на local changes

Значит правки лежат в `main`, а не в своей ветке. В GitHub Desktop: `Current Branch → New Branch` — он перенесёт изменения в новую ветку, после этого `main` снова чистый и `pull.py` проходит. Так теряется меньше всего.
