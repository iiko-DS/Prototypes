# Архив

Устаревшее не удаляем — переносим сюда. Причина простая: через полгода кто-нибудь спросит «а почему мы решили именно так?», и ответ должен находиться.

## Как переносить

1. Переместить файл или папку сюда, сохранив структуру (`09-archive/02-design-system/…` для документов о системе и так далее).
2. **В начало файла добавить строку:**

   ```
   > Устарело <дата>. Вместо этого: <ссылка на актуальный документ>.
   ```

3. Если документ заменён другим в этой же базе — поставить ссылку и там («заменяет `06-archive/…`»), чтобы связь читалась в обе стороны.
4. Записать строку в [`../README.md`](../README.md)? Не нужно: карта должна показывать актуальное, а архив — историю. Достаточно того, что архив виден из карты.

## Что сюда не попадает

- Черновики, которые ещё в работе — им место в ветке, а не в архиве.
- Секреты и доступы — их не храним вообще, ни здесь, ни в истории.
