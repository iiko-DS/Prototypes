  1. 1Table content row: нет состояния «строка с ошибкой» — в макете ошибочные строки подсвечены фоном (переменная Overlay/Error → Negative/50), под них завязан фильтр «Показать только товары с ошибками». Доправить: вариант/модификатор Error у строки + CSS-токен фона. (Фигма + CSS)
  2. 2Редактируемые ячейки (input-cell / select-cell / input-number): ховер вешает рамку #9E9E9E на САМУ ячейку — в покое рамки нет, при наведении +1 px и раскладка «скачет», а рамка дублирует рамку поля внутри. Доправить: рамку состояния рисовать кадру поля, а не ячейке. (CSS)
  3. 3Input number: в Фигме есть свойство Close icon (вариант с иконкой «×»), класса/варианта в CSS нет — очистку поля пришлось собрать слотом __icon. Доправить: вариант Close icon + CSS (как у Input). (Фигма + CSS)
  4. 4Кадры полей (__frame): у input-cell__frame / select-cell__frame не заданы внутренние паддинги (текст липнет к рамке); у input-number__frame и input-datepicker__frame нет box-sizing: border-box — при height: 48 px и паддингах 12 (×2) кадр фактически 74 px (тот же корень, что на странице рекомендаций). Доправить: паддинги + box-sizing в CSS. (CSS)
  5. 5Input number: у .ds-input-number не задан align-items — когда ячейка тянется по высоте строки (редактируемая таблица), «×» прилипает к верху, «%»/«₽» — к низу: детали разъезжаются по вертикали. В прототипе центрируем на странице. Доправить: align-items: center в CSS. (CSS)
  6. 6Статус: подпись не берёт цвет варианта — у .ds-status__label жёстко прописан нейтральный цвет (--ds-color-status-neutral-filled-text-color), поэтому у Warning/Filled текст серый #616161 вместо #ea7806 (в макете подпись оранжевая). Рядом — автоген у .ds-status__content: background задан color-токеном. Доправить: цвет подписи не задавать (наследуется от варианта), background у __content — из Background-токена. (CSS)
