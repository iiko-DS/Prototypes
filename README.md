# База знаний по дизайн-системе iiko

Здесь лежит всё, что нужно, чтобы **правильно работать** с дизайн-системой: с чего начать, какие правила, как решать типовые задачи, что говорить ИИ-агентам. Сама ДС — это четыре других репозитория организации [iiko-DS](https://github.com/iiko-DS); этот репозиторий её не собирает и не изменяет, поэтому клонировать его можно куда угодно и отдельно.

## Что где

| Папка | Что внутри |
|---|---|
| [`01-start/`](01-start/) | с чего начать: доступ в организацию, установка, клонирование, запуск страниц |
| [`02-rules/`](02-rules/) | правила работы: `main`, ветки, Pull Request, что коммитим |
| [`03-howto/`](03-howto/) | рецепты на каждый день: поправить значение, обновить базу, предложить правку |
| [`04-agents/`](04-agents/) | инструкции и скиллы для ИИ-агентов (Copilot, Claude, Hermes) |
| [`05-research/`](05-research/) | разборы, аналитика, замеры, исследования |
| [`06-archive/`](06-archive/) | устаревшее: не удаляем, складываем сюда с пометкой |

## С чего начать

- **Первый раз за компьютером** → [`01-start/`](01-start/): две установки и три команды, плюс как получить доступ.
- **Начинаешь править ДС** → [`02-rules/`](02-rules/): почему в `main` не пишем напрямую и как предложить свою правку.
- **Работаешь с ИИ-агентом** → [`04-agents/`](04-agents/): правила и скиллы, чтобы агент собирал интерфейсы из компонентов ДС, а не из самодельных стилей.

## Где лежит сама дизайн-система

| Репозиторий | Что это |
|---|---|
| [`iiko-ds`](https://github.com/iiko-DS/iiko-ds) | генератор страниц, данные компонентов, `serve.py` — точка входа для работы |
| [`iiko-ds-web`](https://github.com/iiko-DS/iiko-ds-web) | десктопный слой: компоненты, токены, стили, спецификация `iiko-ds-spec.md` |
| [`iiko-ds-mobile`](https://github.com/iiko-DS/iiko-ds-mobile) | мобильный слой ДС |
| [`iiko-ds-prototypes`](https://github.com/iiko-DS/iiko-ds-prototypes) | прототипы экранов (в том числе KDS) |

## Как добавить сюда своё

1. Создать ветку: `имя/что-делаю`, например `ivan/howto-dialog`.
2. Внести правку.
3. `Push origin` → `Create Pull Request` в `main`.

Подробно — [`02-rules/`](02-rules/). Коротко: в `main` напрямую не пишем, потому что на бесплатном плане ветку технически защитить нельзя и вся защита держится на договорённости.
