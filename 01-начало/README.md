# С чего начать

Короткая версия для человека, который подключился впервые: что получить, что установить, что запустить.

## 1. Получить доступ

Репозитории приватные, без приглашения ничего не склонируется.

1. Владелец организации добавляет вас в `iiko-DS`: `https://github.com/orgs/iiko-DS/people` → `Invite member` (нужен ваш логин на GitHub).
2. Приглашение приходит на почту, его надо принять.
3. После этого вы видите все четыре репозитория ДС на чтение. Права писать (свои ветки и PR) даёт команда `design-system` — их выдаёт владелец, см. [`../02-процесс/совместная-работа.md`](../02-процесс/совместная-работа.md).

Проверить, что доступ есть: открыть `https://github.com/iiko-DS/iiko-ds` — должна открыться страница репозитория, а не 404.

## 2. Установить две вещи

- **GitHub Desktop** — `https://desktop.github.com`. Войти в свой аккаунт GitHub; пароли и токены вводить руками не нужно.
- **Python 3** — `https://www.python.org/downloads/`. На Windows при установке отметить галочку **Add Python to PATH**.

Проверить Python (в Windows: `Win+R` → `cmd`):

```
python --version
```

Нужен ответ вида `Python 3.x.x`. Если команда не найдена — Python не в PATH, переустановить с той же галочкой и перезапустить терминал.

## 3. Склонировать четыре репозитория в одну папку

Создать папку, например `DS`. Все четыре репозитория — **рядом в ней**, имена папок менять нельзя: генератор страниц ищет соседние папки по относительным путям.

В GitHub Desktop: `File → Clone repository → GitHub.com` и по очереди склонировать в ту же папку:

```
iiko-DS/iiko-ds              генератор, данные, serve.py
iiko-DS/iiko-ds-web          компоненты, токены, стили
iiko-DS/iiko-ds-mobile       мобильный слой ДС
iiko-DS/iiko-ds-prototypes   прототипы экранов
```

Этот репозиторий (база знаний) клонировать рядом **не нужно** — он не участвует в сборке, читается прямо на GitHub.

## 4. Запустить страницы

В папке `DS` открыть терминал:

```
python doctor.py    # проверка: всё ли на месте, куда смотрят адреса
python start.py     # собрать страницы и открыть локальный сервер
```

Сервер напечатает адрес, обычно такой:

```
http://127.0.0.1:8899/iiko-ds-mobile/prototypes/recommendations/index.html
```

Это список всех компонентов ДС. Остановить сервер — `Ctrl+C`.

Отдельно есть `python pull.py` — забирает свежий `main` из всех четырёх репозиториев, чтобы база была актуальной.

## Если что-то не работает

| Симптом | Что делать |
|---|---|
| Репозиторий не клонируется, в списке его нет | Нет доступа — попросить приглашение в организацию |
| `python: command not found` | Python не в PATH: переустановить с галочкой «Add Python to PATH», перезапустить терминал |
| Страницы собрались, но без стилей | Папки `iiko-ds-web` или `iiko-ds-mobile` нет рядом с `_audit` — проверить раскладку папок |
| `Порт 8899 занят` | `python start.py 9000` или остановить старый сервер |
| Непонятная ошибка | `python doctor.py` — он проверяет окружение и говорит, что именно не так |
| `pull` ругается на local changes | Правки лежат в `main` вместо своей ветки — перенести их в ветку (в GitHub Desktop: `Current Branch → New Branch` переносит изменения) |
